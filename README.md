This is a 1.20.1/26.1 (Neo)Forge/Fabric port of [catboybinary's O123456789.](https://modrinth.com/mod/o123456789) This
mod changes the item count numbers to those from Create mod.

The numbers have been taken from Create mod's stock GUI.
